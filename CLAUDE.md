# CS 1350 coursework

Drew's Python homework, midterm and mini project for CS 1350 at Indiana Tech. Each `.py` file is a separate standalone assignment, run with `python3 <file>`; there is no package, test suite or dependency file.

## Rules

- This is graded coursework. Explain and guide; don't rewrite a whole assignment unless Drew asks for that.
- Keep to what each assignment allows (for example, HW7 uses plain text file operations only, no csv, json or pickle). Read the comment block at the top of a file before changing it.
- Use only the Python standard library unless Drew says otherwise.
- Don't rename or move assignment files; their names are what got submitted.
